StreetZone es una tienda de ropa urbana desarrollada como proyecto web, diseñada para ofrecer una experiencia sencilla e intuitiva de compra en línea. La aplicación permite a los usuarios explorar un catálogo de productos, agregar artículos a un carrito de compras, gestionar cantidades y realizar una simulación de compra.
